# Brief — 1 page + 1 article + 1 post Google, tout en ligne le 30/10

## Demande
Mettre en ligne aujourd'hui, dans **une seule PR**, la page `/application-web-sur-mesure` et l'article `/blog/cahier-des-charges-application` ; puis post Google (fiche d'établissement) vers l'article. Objectif de Loïc : CTR du post ≥ 3 %.

## Décisions tranchées (et pourquoi)
1. **Une seule page aujourd'hui, pas deux.** Page + article + menu (~34 pages) + QC (≤ 2 allers-retours) + fusion dans la journée : une 2e page au seuil 8/10 ne tient pas. Aucune 2e page n'a de demande nette non dépendante de Sacha (intranet : « intranet pme », « intranet sur mesure » = 0 suggestion pertinente ; réservation : « logiciel de réservation sur mesure » = 0, la tête = logiciels du marché par secteur ; interventions : 8 suggestions mais à différencier de `/bon-intervention-numerique` ; n8n / mobile / chatbot écartés : Sacha).
2. **Page = semaine 4 du plan, avancée** : ne dépend de rien d'extérieur ; le site dit déjà ce qu'elle promet (transport l.813 « Une application web : rien à installer » ; /logiciel-sur-mesure l.845 « sur ordinateur, tablette et téléphone, sans rien installer » ; FAQ BTP l.989 « s'ouvre dans le navigateur… écran d'accueil, comme une application »).
3. **Article = « Cahier des charges d'une application : modèle en 1 page »** (au lieu de l'article CRM de la sem. 3 ; sujet déjà dans la liste « articles 3-6 mois » du plan, « cahier des charges simple »). L'article CRM cannibaliserait `/crm-sur-mesure` (en ligne depuis le 27/10, contient déjà « CRM du marché ou CRM sur mesure ? », « Développement de votre CRM sur mesure », « Ce qui fait varier le prix d'un CRM sur mesure ») → décalé, angle distinct à trouver (ex. « CRM ou Excel pour une TPE »).
4. **Post Google type « Offre » vers l'article, modèle gratuit en appât** : seul type pour lequel Google dit publier des « consultations et clics », et meilleur CTR publié.

## Critères de réussite
- Post (J+7, J+28) : CTR ≥ 3 % (ou estimation) ; clics vers le site > semaine de référence.
- Page : indexée ≤ J+14 ; à J+28 ≥ 1 requête « application web » avec impressions ; une URL par requête ; pas de perte de /logiciel-sur-mesure sur « logiciel sur mesure ».
- Article : indexé ≤ J+14 ; impressions sur « cahier des charges application » à J+28 ; verdict J+56.
