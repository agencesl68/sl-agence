Facture électronique : ce qui est déjà obligatoire pour votre entreprise.

Depuis le 1er septembre 2026, toutes les entreprises doivent pouvoir recevoir des factures électroniques. Si vous êtes artisan ou dirigeant de TPE dans le Haut-Rhin, l'obligation d'en émettre arrive le 1er septembre 2027.

Ce qu'il faut faire maintenant :
- choisir une plateforme agréée pour recevoir les factures de vos fournisseurs ;
- vérifier que votre logiciel de facturation sait émettre le bon format ;
- compléter le numéro SIREN de vos clients professionnels ;
- prévenir votre expert-comptable.

Un PDF envoyé par e-mail ne sera plus conforme entre entreprises. Dans le bâtiment, les factures de situation et l'autoliquidation de la TVA se vérifient avec votre comptable.

Notre guide donne la checklist, les amendes prévues et les sources officielles.
