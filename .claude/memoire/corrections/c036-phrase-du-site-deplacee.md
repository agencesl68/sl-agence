# Phrase du site déplacée : son référent change

## Ce qui s'est passé
Le 02/11, dans la version de repli du post Google n°2, la phrase « …ils ne font pas partie de cet outil » (reprise de /crm-sur-mesure, où elle suit le cas du cabinet) a été placée après « Nous développons un CRM… » : « cet outil » désignait alors notre CRM, et le post se contredisait.

## Règle désormais
Une phrase reprise du site qui contient « cet / ce / ces / ci-dessus / plus haut » se place juste après l'élément auquel elle renvoie sur la page source ; sinon, on nomme l'élément.

## Vérification (contrôle qualité)
Pour chaque démonstratif d'une phrase reprise, comparer le paragraphe qui précède dans le livrable et sur la page source.
