# Premier écran du site surchargé

## Ce qui s'est passé
Maquette de l'accueil (étape 1) : titre + accroche + 2 boutons + 3 infos + bulle + téléphone + fil animé +
3 pastilles flottantes + onglets + lien. Loïc : « trop d'informations », « un peu le foutoir », il veut plus épuré.

## Règle désormais
Sur un écran du site, une seule chose bouge et attire l'œil. Le premier écran se limite à : titre, une phrase,
les boutons d'action, l'animation principale et ses contrôles. Pas de pastilles décoratives, pas de lien
secondaire sous une animation, pas d'effets de fond qui clignotent.

## Vérification (contrôle qualité)
Compter les éléments du premier écran : si on peut en retirer un sans perdre le message, il faut le retirer.
