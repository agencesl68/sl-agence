# Mots de métier ou compliqués dans les textes du site

## Ce qui s'est passé
05/11, relecture de la réécriture de l'accueil : Loïc demande des mots simples que tout le monde comprend, sans jargon du métier (informatique, automatisation, administratif), mais sans que le texte devienne enfantin.

## Règle désormais
Chaque mot d'un texte visible (site, posts, messages) doit être compris par un artisan ou un commerçant qui n'a jamais travaillé avec un informaticien. Jargon interdit dans le texte courant : ressaisie, saisie (préférer « taper », « noter », « remplir »), interface, outil connecté, workflow, process, flux, synchroniser, intégration, API, CRM (sauf s'il est expliqué), agent IA (sauf s'il est expliqué), dématérialisation, back-office, solution, optimiser, digitaliser, centraliser.
On garde : les mots-clés SEO des titres (« automatisation », « logiciel sur mesure ») et les noms d'outils que le client utilise déjà (Excel, Gmail, Sage…).
Pas de ton enfantin : pas de « super », pas de points d'exclamation, pas d'explications du type « un logiciel, c'est… ». Phrases courtes, mots de tous les jours, vouvoiement.

## Vérification (contrôle qualité)
Relire chaque phrase en se demandant : « un plombier de 55 ans comprend-il chaque mot du premier coup ? ». Chercher la liste ci-dessus dans le texte visible.
