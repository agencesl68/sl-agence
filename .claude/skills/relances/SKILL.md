# /relances — qui relancer aujourd'hui

1. Lancer l'agent `crm-relances`.
2. Vérifier que chaque relance indique : entreprise, dernier contact, date, situation, prochaine action,
   message recommandé — et que les dates manquantes sont signalées, pas inventées.
3. Présenter d'abord les demandes entrantes non traitées, puis les relances du jour, puis les oubliés.
4. Proposer les mises à jour de statut à faire dans la feuille / le CRM.
