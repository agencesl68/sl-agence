# /relances — rien n'est oublié

## Chaîne (obligatoire)

QG : agent(s) « au travail » + activité → **suivi** (exécution, Sonnet) →
**controle-qualite** (verdict ; si À CORRIGER, renvoyer à l'agent, 2 fois max) → présentation à Loïc
→ QG : livrables, mission, agents « disponibles » → commit.

## Étapes

1. **Suivi** exécute :
   - **Gmail** : fils `SL Prospection/…`, envois récents, réponses ; libellés mis à jour ;
   - **Calendar** : rendez-vous passés/à venir ; 2 créneaux libres proposés dans chaque relance ;
   - **Gmail** : brouillon de relance dans le même fil (jamais d'envoi) ;
   - **Sheets** : Statut, Date du contact, Date de relance mis à jour.
2. **Contrôle qualité** : chaque relance (grille e-mailing, corrections c005 c010).
3. **Notion** (si connecté) : tâches « Répondre à X (a répondu) » en priorité haute, « Envoyer N relances ».
4. Présenter : réponses reçues d'abord, puis relances du jour, puis oubliés ; une question groupée pour
   ce que Gmail ne voit pas (LinkedIn, téléphone).
